## IO2 ADC 四键技术细节

### 硬件原理

- **接口**: GPIO2 (ADC1_CH1, ESP32-S3)
- **ADC 配置**: 12-bit, 0-3.3V 量程 (ADC_ATTEN_DB_11)
- **采样方式**: 8 次采样取平均，提高稳定性
- **消抖时间**: 50ms

### 电压阈值表

| 按键 | 分压电阻 | 实测电压 | 检测范围 (mV) |
|------|---------|---------|--------------|
| 按键 1 (UP) | 10kΩ | ~1576 mV | 1300 ~ 2100 |
| 按键 2 (DOWN) | 220Ω | ~43 mV | 0 ~ 150 |
| 按键 3 (LEFT) | 1kΩ | ~261 mV | 150 ~ 600 |
| 按键 4 (RIGHT) | 4.7kΩ | ~1017 mV | 600 ~ 1300 |
| 未按键 | - | ~3300 mV | > 2100 |

### 关键代码片段

```cpp
// ADC 初始化 (与 ESP-NOW 兼容，使用 ADC1 不受 WiFi 影响)
adc1_config_width(ADC_WIDTH_BIT_12);
adc1_config_channel_atten(ADC_KEY_CHANNEL, ADC_ATTEN_DB_11);

// 按键识别逻辑
static adc_key_t adc_get_key(uint32_t *out_voltage) {
    uint32_t voltage = adc_read_voltage_mv();  // 8 次采样平均
    if (voltage >= 1300 && voltage < 2100) return ADC_KEY_UP;       // 按键1
    if (voltage >= 0    && voltage < 150)  return ADC_KEY_DOWN;     // 按键2
    if (voltage >= 150  && voltage < 600)  return ADC_KEY_LEFT;     // 按键3
    if (voltage >= 600  && voltage < 1300) return ADC_KEY_RIGHT;    // 按键4
    return ADC_KEY_NONE;
}

// 按键4双击检测（500ms 窗口内连续两次短按触发演示模式）
if (prev_adc_key == ADC_KEY_RIGHT && !is_long_press) {
    if (now - adc_key4_last_release <= 500) {
        adc_key4_click_count++;
        if (adc_key4_click_count >= 2) {
            inject_demo_data();  // 进入演示模式
        }
    }
}
```

## 技术实现

### I2C 按键 A/B 检测逻辑

```cpp
// 阈值定义
const uint32_t LONG_PRESS_MS = 600;         // 长按阈值 600ms
const uint32_t REPEAT_INTERVAL_MS = 100;    // 长按 B 重复间隔 100ms

// 按键状态
static bool prev_a = false;                 // 按键 A 上一帧状态
static bool prev_b = false;                 // 按键 B 上一帧状态
static uint32_t press_time_a = 0;           // 按键 A 按下时间戳
static uint32_t press_time_b = 0;           // 按键 B 按下时间戳
static uint32_t last_repeat_b = 0;          // 按键 B 上次重复时间
```

### ADC 四键检测逻辑

```cpp
// ADC 配置
#define ADC_KEY_PIN     2                   // GPIO2 (ADC1_CH1)
#define ADC_SAMPLES     8                   // 8 次采样平均
#define ADC_DEBOUNCE_MS 50                  // 消抖 50ms

// ADC 按键状态
static adc_key_t prev_adc_key      = ADC_KEY_NONE;
static uint32_t  adc_press_time    = 0;     // 按下时间戳
static uint32_t  adc_press_voltage = 0;     // 按下时电压（调试用）
static uint32_t  adc_last_read     = 0;     // 上次采样时间

// 按键4双击检测
static uint8_t   adc_key4_click_count = 0;
static uint32_t  adc_key4_last_release = 0;
static const uint32_t ADC_DOUBLE_CLICK_WINDOW_MS = 500;
```

### 按键 A 逻辑

**按下时**：记录时间戳 `press_time_a`，不发送  
**释放时**：
- 持续时间 < 600ms → **短按**：发送 F2，切换音频流
- 持续时间 ≥ 600ms → **长按**：发送 Esc，不切换音频流

### 按键 B 逻辑

**按下时**：记录时间戳 `press_time_b`  
**持续按住**：
- 持续时间 ≥ 600ms → 进入长按模式，每 100ms 发送一次 Backspace（按下+释放）
**释放时**：
- 持续时间 < 600ms → **短按**：切换屏幕
- 持续时间 ≥ 600ms → **长按**：不发送（已在持续期间发送）

### ADC 按键 1 (UP) 逻辑 — 完全复用按键 A

**正常模式**:
- **短按**: 发送 F2 + 切换音频流 — 与按键 A 完全一致
- **长按**: 发送 Enter — 确认操作

**演示模式**（屏幕专属交互，与按键 A 行为一致）:
| 屏幕 | 短按 | 长按 |
|------|------|------|
| 屏幕 1 (Token) | 循环高亮下一行 | 重置当前项进度 |
| 屏幕 2 (Coding) | 切换选择题选项 A↔B | 确认选择 |
| 屏幕 3 (Inspo) | 重启打字机动画 | 跳过显示全文 |
| 屏幕 4 (Profile) | （无） | 切换用户头像 |

### ADC 按键 2 (DOWN) 逻辑

- **短按**: 发送 Enter（确认）
- **长按**: 发送 Esc（取消）

### ADC 按键 3 (LEFT) 逻辑

- **短按**: 发送 Backspace（删除单个字符）
- **长按**: 发送 Ctrl+Backspace（删除整词，modifier=0x01 Left Ctrl + keycode=0x2A）

### ADC 按键 4 (RIGHT) 逻辑

- **短按**: 切换屏幕（与按键 B 短按功能相同）
- **长按**: 无功能
- **双击** (<500ms 内连续两次短按): 触发演示模式 (`inject_demo_data()`)

## 使用场景

### 场景 1：语音输入文件名（按键 A 或 ADC 按键 1）

1. 在资源管理器选中文件
2. **短按 A** 或 **短按 ADC-1** → 进入重命名模式 + 开始录音
3. 说出新文件名
4. **短按 A** 或 **短按 ADC-1** → 停止录音
5. **长按 A** 或 **短按 ADC-2** → 确认提交（Enter）

### 场景 2：输错了取消重来

1. **短按 A/ADC-1** → 开始语音输入
2. 说了一半发现错了
3. **长按 ADC-2** → Esc 取消操作
4. 重新开始

### 场景 3：删除多余内容（多种删除方式）

**单个字符删除**:
1. 语音输入完成后发现多了几个字
2. **短按 ADC-3** → 单次删除一个字符
3. **短按 ADC-2** → Enter 确认

**连续删除**:
1. **长按 B** → 持续删除多余字符（每 100ms 重复）
2. 松开后停止删除
3. **短按 B** → 切换屏幕（或 **短按 ADC-2** 确认）

**删除整词**:
1. **长按 ADC-3** → Ctrl+Backspace 删除光标前的整个单词
2. **短按 ADC-2** → Enter 确认

### 场景 4：清空输入重填

1. 输入框里有一段旧内容
2. **长按 B** → 快速删除全部内容（连续 Backspace）
3. **短按 A/ADC-1** → 开始语音输入新内容
4. **长按 A** 或 **短按 ADC-2** → 确认提交

### 场景 5：快速进入演示模式

**方法 1（原生）**: 同时按住 A+B 2 秒  
**方法 2（ADC）**: **双击 ADC-4**（500ms 内连续两次短按）

### 场景 6：演示模式下的交互式操作

进入演示模式后，**按键 A** 或 **ADC-1** 在不同屏幕有专属交互：

- **屏幕 1 (Token 使用)**:
  - 短按 → 循环高亮下一个服务
  - 长按 → 重置当前高亮项的进度到 10%

- **屏幕 2 (Coding 状态)**:
  - 短按 → 切换选择题选项 A↔B
  - 长按 → 确认选择（显示 ✓ 图标）

- **屏幕 3 (产品灵感)**:
  - 短按 → 重启打字机动画（逐字显示 + 闪烁光标）
  - 长按 → 跳过动画直接显示全文

- **屏幕 4 (用户资料)**:
  - 长按 → 切换用户头像（循环 SD 卡中的 user.png / user1.png ...）

## 设计原则

### 直觉化配对（原生 A/B 键）

- **A 短按（F2）= 开始操作** ↔ **A 长按（Enter）= 确认完成**
- **B 短按（切换屏幕）= 导航** ↔ **B 长按（Backspace）= 后退删除**

### ADC 四键设计思路

**按键 1 (UP)**: 完全复用按键 A 逻辑
- 目的：提供冗余操作方式，防止 I2C 按键失效时仍可正常使用
- 实现：调用与按键 A 完全相同的处理函数，包括演示模式的屏幕专属交互

**按键 2-4**: 功能互补与扩展
- **按键 2 (DOWN)**: Enter/Esc 确认/取消对（短按确认 + 长按取消，符合直觉）
- **按键 3 (LEFT)**: 删除功能增强（短按单字符 + 长按整词，提高编辑效率）
- **按键 4 (RIGHT)**: 屏幕切换 + 双击触发演示模式（高频操作优化）

### 手感优先

- 短按/长按靠手感区分，无需看屏幕
- 不使用双击（除按键 4 特殊场景，因其为低频操作）
- 不使用组合键（两键同时按易误触）
- ADC 采样 8 次平均 + 50ms 消抖，确保识别稳定

### 功能覆盖扩展

**原生 A/B 键**（4 个手势）覆盖语音输入核心操作：
1. **输入**（F2 + 音频流）
2. **确认**（Enter）
3. **删除**（Backspace 连续）
4. **切换**（屏幕导航）

**ADC 四键**（8 个手势 + 双击）扩展高级功能：
1. **冗余输入**（ADC-1 = 按键 A 完整逻辑）
2. **快速确认**（ADC-2 短按 Enter）
3. **快速取消**（ADC-2 长按 Esc）
4. **单字符删除**（ADC-3 短按）
5. **整词删除**（ADC-3 长按 Ctrl+Backspace）
6. **屏幕切换**（ADC-4 短按，与 B 键互补）
7. **演示模式**（ADC-4 双击，单手触发）
8. **屏幕专属交互**（ADC-1 在演示模式下各屏幕的独立行为）

### ADC 硬件优势

- **ESP32-S3 ADC1 不受 WiFi 影响**：与 ESP-NOW 共存无干扰
- **电压分级稳定**：四个电压范围间隔足够大（>150mV），误触率低
- **单 GPIO 节省引脚**：4 个按键仅占用 1 个 GPIO2（ADC1_CH1）
- **易于扩展**：可通过更多分压电阻扩展到 8 键（理论上限受 ADC 精度约束）

- 电压阈值校准：0-150mV / 150-600mV / 600-1300mV / 1300-2100mV

- 与原生 I2C 按键 A/B 并存，互不冲突
