## 系统架构

```
K10 (3c:dc:75:6d:7f:b4)
  ├─ I2S 麦克风 (ES7243E @ 16kHz)
  ├─ 按键 A/B (XL95x5 扩展 GPIO)
  ├─ LCD 240×320 (ILI9341 + LVGL)
  └─ ESP-NOW 发送端 (Channel 1)
        ↓
Dongle (e0:72:a1:d4:8f:e0)
  ├─ ESP-NOW 接收端 (Channel 1)
  ├─ USB HID 键盘 (VID_303A:PID_8000 MI_00)
  └─ USB UAC 麦克风 (VID_303A:PID_8000 MI_01)
        ↓
Windows PC
  ├─ 设备管理器识别 HID + Audio
  └─ Claude Code (接收 F2/Enter 按键)
```
