# K10 按键 A → PC F2 键测试说明

## 功能描述

K10 的按键 A (eP5_KeyA) 按下/释放时，会通过 ESP-NOW 发送按键帧给 Dongle，Dongle 转发为 USB HID 键盘的 F2 键到 PC。

**数据流**:
```
K10 按键 A 按下/释放 
  → ESP-NOW 按键帧 (FRAME_TYPE_KEY) 
  → Dongle 接收 
  → USB HID Keyboard (F2 key)
  → PC
```

## 测试前准备

### 1. 硬件连接
- **K10 (COM4)**: USB 线连接到 COM 口（串口监视），WiFi 无线连接
- **Dongle (COM6)**: 
  - 烧录时：USB 线连接到 COM 口
  - 测试时：**USB 线连接到 USB 口**（枚举为 HID 键盘）

### 2. 确认 Dongle 已枚举为 USB HID 键盘

打开 **设备管理器** (Win+X → 设备管理器)：

```
├── 人体学输入设备
│   └── HID Keyboard Device
│       └── HID\VID_303A&PID_8000&MI_00
└── 声音、视频和游戏控制器
    └── CodeBuddy Wireless Dongle
        └── USB\VID_303A&PID_8000&MI_01
```

✅ 如果看到 `HID Keyboard Device`，说明 Dongle USB HID 已就绪

### 3. 配置检查

**K10 配置** (`51_mic_wifi.ino` 第 26-27 行):
```cpp
static uint8_t dongle_mac[6] = {0xe0, 0x72, 0xa1, 0xd4, 0x8f, 0xe0};  // Dongle MAC
static const int ESPNOW_CHANNEL = 1;  // 信道必须一致
```

**Dongle 配置** (`dongle_firmware/main/config.h`):
```c
#define ESPNOW_CHANNEL 1
static uint8_t k10_mac[6] = {0x3c, 0xdc, 0x75, 0x6d, 0x7f, 0xb4};  // K10 MAC
```

## 故障排查

### 问题 1: K10 串口显示 "Key frame send FAILED: XXX"

**原因**: ESP-NOW 未成功发送
- 检查 Dongle 是否上电
- 检查 ESP-NOW 信道是否一致 (都设为 1)
- 检查 Dongle MAC 地址是否正确

### 问题 2: Dongle 串口无 "HID Report" 输出

**原因**: Dongle 未接收到按键帧
- 检查 K10 MAC 地址是否在 Dongle 配置中
- 检查 ESP-NOW 信道是否一致
- 查看 Dongle 日志是否有 "ESP-NOW audio packet received" (说明通信正常)

### 问题 3: PC 应用无 F2 反应

**原因**: Dongle USB HID 未枚举或无焦点
- 检查设备管理器是否有 "HID Keyboard Device"
- 确认 Dongle USB 线连接到 **USB 口**（不是 COM 口）
- 确认测试应用窗口有焦点（点击一下窗口）

### 问题 4: K10 LCD 显示 "ESPNOW FAIL"

**原因**: ESP-NOW 初始化失败
- 重启 K10 设备
- 检查 WiFi 配置
- 查看串口详细错误信息

## 技术细节

### 按键帧数据结构 (espnow_protocol.h)

```c
typedef struct __attribute__((packed)) {
    uint8_t  frame_type;      // 0x01 = FRAME_TYPE_KEY
    uint8_t  action;          // 1=按下, 0=释放
    uint8_t  modifier;        // HID 修饰键 (Ctrl/Shift/Alt/GUI)
    uint8_t  keycode[6];      // HID 键码数组，最多 6 键同时
    uint16_t timestamp;       // 时间戳 (ms)
    uint8_t  seq_num;         // 序列号
    uint8_t  crc8;            // CRC8 校验
} key_frame_t;  // 总计 13 字节
```

### HID 键码映射

| 按键 | HID 键码 | 说明 |
|-----|---------|------|
| F2  | 0x3B    | 当前实现 |
| F1  | 0x3A    | 可选 |
| F3  | 0x3C    | 可选 |
| Enter | 0x28  | 可选 |

**修改键码位置**: `51_mic_wifi.ino` 第 286 行
```cpp
key_frame.keycode[0] = 0x3B;   // F2 键,改为其他 HID 键码可选
```
