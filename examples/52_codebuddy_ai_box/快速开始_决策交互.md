# 快速开始：CodeBuddy AI BOX 决策交互

## 5 分钟快速体验

### 第一步：烧录固件（首次使用）

```bash
# 在项目根目录
python -m platformio run -t upload -e 52_codebuddy_ai_box --upload-port COM11
```

**等待输出**：`SUCCESS` 提示

### 第二步：启动守护进程

```bash
cd examples/52_codebuddy_ai_box/pc_tools
python atkbox_daemon.py --port COM6
```

**看到提示**：
```
[INFO] IPC server listening on 127.0.0.1:47100
```

### 第三步：运行测试（新终端）

```bash
# 保持上面的守护进程运行，新开终端
cd examples/52_codebuddy_ai_box/pc_tools
python test_decision_with_keyboard.py
```

### 第四步：选择输入方式

**方式 1：ATK BOX 触摸**
- BOX 屏幕显示：
  ```
  Choose database:
  ━━━━━━━━━━━━━━━━━━
  [1. PostgreSQL   ]  ← 触摸这里
  [2. MongoDB      ]
  [3. MySQL        ]
  [4.              ]
  ━━━━━━━━━━━━━━━━━━
       [confirm]     ← 再触摸确认
  ```

**方式 2：PC 键盘输入**
- 守护进程终端显示：
  ```
  ============================================================
    Keyboard input enabled:
    [1] PostgreSQL
    [2] MongoDB
    [3] MySQL
    Type number (1-4) or option text, then press Enter
  ============================================================
  ```
- 输入以下任意一种：
  - `1` + Enter → 选择 PostgreSQL
  - `postgres` + Enter → 模糊匹配 PostgreSQL
  - `mongo` + Enter → 模糊匹配 MongoDB

### 第五步：查看结果

测试脚本显示：
```
✓ 用户选择: [0] PostgreSQL
  来源: KEYBOARD
```

## 常见问题速查

### Q: 守护进程启动失败？

```bash
# 检查端口占用
netstat -an | findstr "47100"

# 检查 Dongle 连接
python -m serial.tools.list_ports
# 应该看到 COM6
```

### Q: BOX 显示空白？

```bash
# 查看串口输出
python -m platformio device monitor -p COM12 -b 115200
# 看到 "Decision req id=..." 说明收到请求
```

### Q: 键盘输入不生效？

- 确认焦点在守护进程终端窗口
- Windows 专用，Linux/macOS 需修改代码

### Q: 想在自己的 Python 代码中调用？

```python
import socket, json

def ask_user(title, options):
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect(("127.0.0.1", 47100))
    
    request = json.dumps({
        "type": "decision",
        "title": title,
        "options": options
    }) + "\n"
    
    sock.sendall(request.encode("utf-8"))
    response = sock.recv(4096).decode("utf-8")
    sock.close()
    
    result = json.loads(response)
    return result["chosen"] if result["ok"] else None

# 使用
choice = ask_user("Continue?", ["Yes", "No"])
if choice == 0:
    print("Continuing...")
```
