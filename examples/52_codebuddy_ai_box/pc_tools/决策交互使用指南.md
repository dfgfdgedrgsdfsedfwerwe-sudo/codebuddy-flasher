# CodeBuddy AI BOX 决策交互使用指南

## 系统架构

```
PC 端                     Dongle (COM6)              ATK BOX (COM12)
┌─────────────────┐      ┌──────────────┐          ┌─────────────────┐
│ Python 脚本     │─IPC→│ atkbox_daemon│←ESP-NOW→│ 固件 (52例)     │
│                 │      │              │          │                 │
│ 键盘监听        │      │ 串口独占     │          │ 触摸界面        │
└─────────────────┘      └──────────────┘          └─────────────────┘
```

## 功能特性

✅ **双输入源**：
- ATK BOX 触摸屏选择（原有功能）
- PC 端键盘输入（新增功能）

✅ **方案 B 显示格式**：
- BOX 显示：`1. PostgreSQL`（数字前缀 + 文本）
- PC 显示：完整选项列表 + 提示

✅ **智能匹配**：
- 输入数字 `1`/`2`/`3`/`4` → 直接匹配
- 输入文本 `postgres` → 模糊匹配 `PostgreSQL`

## 使用流程

### 第一步：启动守护进程

```bash
cd pc_tools
python atkbox_daemon.py --port COM6
```

**日志输出**：
```
[2026-09-09 18:00:00] [INFO] DaemonServer initialized (IPC: 47100, Serial: COM6, PushInterval: 30s)
[2026-09-09 18:00:00] [INFO] Background pusher thread started
[2026-09-09 18:00:00] [INFO] IPC server listening on 127.0.0.1:47100
```

> **注意**：守护进程必须持续运行，所有决策请求都通过它转发。

### 第二步：发送决策请求

#### 方式 1：使用测试脚本

```bash
# 新终端窗口
python test_decision_with_keyboard.py
```

#### 方式 2：集成到你的 Python 代码

```python
import socket
import json

def ask_decision(title, options):
    request = {
        "type": "decision",
        "title": title,
        "options": options  # 1-4 个选项
    }
    
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect(("127.0.0.1", 47100))
    sock.sendall((json.dumps(request) + "\n").encode("utf-8"))
    
    response_data = b""
    while b"\n" not in response_data:
        response_data += sock.recv(1024)
    
    sock.close()
    return json.loads(response_data.decode("utf-8"))

# 使用示例
result = ask_decision("Choose database:", ["PostgreSQL", "MongoDB", "MySQL"])
if result["ok"]:
    chosen = result["chosen"]
    source = result["source"]  # "box" 或 "keyboard"
    print(f"用户选择: {chosen}, 来源: {source}")
```

### 第三步：用户交互

#### ATK BOX 触摸交互（原有功能）

1. BOX 屏幕显示：
   ```
   Choose database:
   ━━━━━━━━━━━━━━━━━━
   [1. PostgreSQL   ]
   [2. MongoDB      ]
   [3. MySQL        ]
   [4.              ]
   ━━━━━━━━━━━━━━━━━━
        [confirm]
   ```

2. 触摸选项 → 变蓝高亮
3. 触摸 `[confirm]` → 发送回执

#### PC 键盘输入（新增功能）

守护进程终端会显示：

```
============================================================
  Keyboard input enabled:
  [1] PostgreSQL
  [2] MongoDB
  [3] MySQL
  Type number (1-4) or option text, then press Enter
============================================================
```

**输入方式**：

| 输入内容 | 匹配结果 | 说明 |
|---------|---------|------|
| `1` + Enter | PostgreSQL | 直接数字匹配 |
| `2` + Enter | MongoDB | 直接数字匹配 |
| `postgres` + Enter | PostgreSQL | 前缀模糊匹配 |
| `mongo` + Enter | MongoDB | 前缀模糊匹配 |
| `sql` + Enter | ❌ 失败 | 无法区分 PostgreSQL/MySQL |
| `mysql` + Enter | MySQL | 全文匹配 |

### 第四步：接收结果

Python 脚本收到响应：

```json
{
  "ok": true,
  "chosen": 0,
  "source": "keyboard"
}
```

- `chosen`: 选择的索引（0-3）
- `source`: 
  - `"box"` = ATK BOX 触摸选择
  - `"keyboard"` = PC 键盘输入

## 典型使用场景

### 场景 1：Claude Code 需要用户决策

```python
# 在 Claude Code 工作流中
from pathlib import Path
import socket, json

def ask_user(title, options):
    # 连接守护进程
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect(("127.0.0.1", 47100))
    
    request = json.dumps({
        "type": "decision",
        "title": title,
        "options": options
    }) + "\n"
    
    sock.sendall(request.encode("utf-8"))
    response = sock.recv(4096).decode("utf-8")
    sock.close()
    
    result = json.loads(response)
    return result.get("chosen") if result.get("ok") else None

# Claude 需要选择数据库
choice = ask_user("Choose database:", ["PostgreSQL", "MongoDB", "MySQL"])
if choice == 0:
    print("Using PostgreSQL...")
elif choice == 1:
    print("Using MongoDB...")
```

## 常见问题

### Q1: 键盘输入不生效？

**检查**：
- 守护进程是否正在运行？`netstat -an | findstr 47100`
- 终端窗口是否获得焦点？（键盘输入在守护进程终端）
- Windows 防火墙是否阻止？

### Q2: BOX 显示空白或乱码？

**原因**：选项文本超过 24 字节（UTF-8 编码）

**解决**：
```python
options = [opt[:24] for opt in original_options]  # 截断到 24 字符
```

### Q3: 超时无响应？

**默认超时**: 60 秒（BOX 端 60s + 守护进程缓冲）

**自定义超时**：
```python
sock.settimeout(120.0)  # 2 分钟
```

### Q4: 多窗口同时决策冲突？

**当前行为**：守护进程串行处理，后到的请求会覆盖前一个

**规避**：单线程调用，或在应用层加锁：
```python
import threading
decision_lock = threading.Lock()

with decision_lock:
    result = ask_user("Question?", ["A", "B"])
```

## 协议细节

### 决策请求帧（0x0A）

```c
typedef struct {
    uint8_t  frame_type;                 // = 0x0A
    uint16_t decision_id;                // 递增 ID
    uint8_t  kind;                       // 0=工具权限 1=多选题
    char     title[32];                  // 标题（UTF-8, 补零）
    uint8_t  opt_count;                  // 选项数 (1-4)
    char     opts[4][24];                // 选项文本（UTF-8, 补零）
    uint8_t  crc8;                       // CRC8 校验
} decision_request_frame_t;              // 134 字节
```

### 决策回执帧（0x0B）

```c
typedef struct {
    uint8_t  frame_type;    // = 0x0B
    uint16_t decision_id;   // 对应请求 ID
    uint8_t  chosen_index;  // 0-3 或 0xFF (取消)
    uint8_t  crc8;
} decision_reply_frame_t;   // 5 字节
```

### 串口封装层

所有帧通过 SerialManager 发送，格式：
```
[A5 5A] [len] [payload] [crc8]
```

## 性能指标

- **决策延迟**（触摸）：< 300ms（用户点击 confirm → PC 收到回执）
- **决策延迟**（键盘）：< 100ms（用户按 Enter → 守护进程处理）
- **并发支持**：单线程串行（多请求排队）
- **内存占用**：守护进程 ~30MB（Python + 串口驱动）
