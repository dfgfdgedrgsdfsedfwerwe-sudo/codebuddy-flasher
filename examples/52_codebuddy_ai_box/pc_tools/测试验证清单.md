## 故障排查

### 问题 1：BOX 显示空白

**排查步骤**：
1. 检查 ESP-NOW 连接：
   ```bash
   # BOX 串口输出应有:
   ESP-NOW init OK
   Peer added: e0:72:a1:d4:8f:e0
   ```

2. 检查帧发送：
   ```bash
   # 守护进程日志应有:
   Decision sent: id=1, title=..., opts=3
   ```

3. 检查 BOX 接收：
   ```bash
   # BOX 串口应有:
   Decision req id=1 kind=1 opts=3
   ```

**常见原因**：
- Dongle MAC 地址错误（`51_mic_wifi.ino:37` 行）
- ESP-NOW 信道不匹配（应为 1）

### 问题 2：键盘输入无响应

**排查步骤**：
1. 确认焦点在守护进程终端
2. 检查线程启动：
   ```python
   # 守护进程日志应有:
   Keyboard listener started
   ```
3. 尝试手动输入测试字符

**常见原因**：
- 终端未获得焦点
- Windows 输入法干扰（切换到英文输入法）
- 权限问题（以管理员运行）

### 问题 3：超时无响应

**排查步骤**：
1. 检查串口连接：
   ```bash
   python -m serial.tools.list_ports
   ```
2. 检查 Dongle 固件版本（应支持 0x0A/0x0B 帧）
3. 增加超时时间（`max_polls` 参数）
