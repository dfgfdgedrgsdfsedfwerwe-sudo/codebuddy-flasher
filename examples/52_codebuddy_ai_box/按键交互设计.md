## 按键映射表

> **ATK BOX 定稿 (2026-08-31)**: 下表为 K10 原始设计。ATK BOX 移植版按下表调整了 A/B 分工——
> 因移除触摸滑动翻页, **翻页改由 B 短按承担**, **Enter 确认移到 A 长按** (取消 Esc)。
> 编号对照: K2=按键A, K1=按键B, K0=BOOT。

**ATK BOX 实际映射 (当前固件):**

| 按键 | 短按 (<0.6秒) | 长按 (≥0.6秒) |
|------|--------------|--------------|
| **K2 = A** | F2 语音输入 + 切换音频流 | Enter 确认 |
| **K1 = B** | 切换到下一个界面 (翻页) | Backspace 连续删除 |
| **K0 = BOOT** | 返回主界面 (AI Status) | 跳转触摸测试界面 |

**K10 原始设计 (历史参考):**

| 按键 | 短按 (<0.6秒) | 长按 (≥0.6秒) |
|------|--------------|--------------|
| **A (eP5_KeyA)** | F2 语音输入 + 切换音频流 | Esc 取消 |
| **B (eP11_KeyB)** | Enter 确认 | Backspace 连续删除 |

| 功能 | HID 键码 | 说明 |
|------|---------|------|
| F2 | 0x3B | 文件重命名 / 语音输入触发 |
| Esc | 0x29 | 取消操作 / 退出对话框 |
| Enter | 0x28 | 确认 / 换行 |
| Backspace | 0x2A | 删除字符 |

## 技术实现

### 短按/长按检测逻辑

```cpp
// 阈值定义
const uint32_t LONG_PRESS_MS = 600;         // 长按阈值 600ms
const uint32_t REPEAT_INTERVAL_MS = 100;    // 长按 B 重复间隔 100ms

// 按键状态
static bool prev_a = false;                 // 按键 A 上一帧状态
static bool prev_b = false;                 // 按键 B 上一帧状态
static uint32_t press_time_a = 0;           // 按键 A 按下时间戳
static uint32_t press_time_b = 0;           // 按键 B 按下时间戳
static uint32_t last_repeat_b = 0;          // 按键 B 上次重复时间
```

### 按键 A 逻辑

**按下时**：记录时间戳 `press_time_a`，不发送  
**释放时**：
- 持续时间 < 600ms → **短按**：发送 F2，切换音频流
- 持续时间 ≥ 600ms → **长按**：发送 Esc，不切换音频流

### 按键 B 逻辑

**按下时**：记录时间戳 `press_time_b`  
**持续按住**：
- 持续时间 ≥ 600ms → 进入长按模式，每 100ms 发送一次 Backspace（按下+释放）
**释放时**：
- 持续时间 < 600ms → **短按**：发送 Enter
- 持续时间 ≥ 600ms → **长按**：不发送（已在持续期间发送）

## 使用场景

### 场景 1：语音输入文件名

1. 在资源管理器选中文件
2. **短按 A** → 进入重命名模式 + 开始录音
3. 说出新文件名
4. **短按 A** → 停止录音
5. **短按 B** → 确认提交

### 场景 2：输错了取消重来

1. **短按 A** → 开始语音输入
2. 说了一半发现错了
3. **长按 A** → Esc 取消操作
4. 重新开始

### 场景 3：删除多余内容

1. 语音输入完成后发现多了几个字
2. **长按 B** → 持续删除多余字符
3. 松开后停止删除
4. **短按 B** → Enter 确认

### 场景 4：清空输入重填

1. 输入框里有一段旧内容
2. **长按 B** → 快速删除全部内容
3. **短按 A** → 开始语音输入新内容
4. **短按 B** → 确认提交

## 设计原则

### 直觉化配对

- **A 短按（F2）= 开始操作** ↔ **A 长按（Esc）= 取消操作**
- **B 短按（Enter）= 前进确认** ↔ **B 长按（Backspace）= 后退删除**

### 手感优先

- 短按/长按靠手感区分，无需看屏幕
- 不使用双击（识别不稳定）
- 不使用组合键（两键同时按易误触）

### 覆盖核心操作

4 个手势覆盖语音输入场景的全部需求：
1. **输入**（F2 + 音频流）
2. **确认**（Enter）
3. **删除**（Backspace 连续）
4. **取消**（Esc）
