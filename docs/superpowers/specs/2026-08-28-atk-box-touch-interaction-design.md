# ATK BOX 交互设计方案（方案 A：渐进式触摸增强）

**项目**: CodeBuddy AI BOX (ATK ESP32-S3 BOX 移植版)
**日期**: 2026-08-28
**设计状态**: ✅ 已确认，待实现
**硬件**: 3 物理按键 (KEY0/KEY1/BOOT) + CHSC5432 单点电容触摸屏 (240×320)

---

## 1. 设计目标

- **增强界面浏览体验**：通过触摸交互让用户深入查看每个界面的详细信息
- **充分利用触摸屏**：单点触摸支持点击、长按、滑动等常见手势
- **保持语音操作直观**：物理按键专注语音输入流程（录音/确认/取消/删除）
- **降低学习成本**：触摸交互遵循常见 UI 规范，符合用户直觉

**约束条件**：
- 触摸屏仅支持**单点触摸**（不支持双指/多点手势）
- 语音输入核心操作（F2/Enter/Esc/Backspace）**全部保留在物理按键**上
- 演示模式触发方式保持不变（A+B 同时按 2 秒）

---

## 2. 物理按键映射表

| 按键 | 短按 (<600ms) | 长按 (≥600ms) | 组合键 |
|------|--------------|--------------|--------|
| **KEY1 (A)** | 切换录音（F2 + 音频流开关） | Esc 取消操作 | A+B 同时 2 秒 = 演示模式 |
| **KEY0 (B)** | Enter 确认 | 连续 Backspace 删除（每 100ms 一次） | - |
| **BOOT (C)** | 返回主界面（AI Status，界面 5） | 进入 TouchTest 调试界面（界面 6） | - |

### HID 键码对照

| 功能 | HID 键码 | 触发方式 |
|------|---------|---------|
| F2 | 0x3B | A 短按 |
| Esc | 0x29 | A 长按 |
| Enter | 0x28 | B 短按 |
| Backspace | 0x2A | B 长按（连续发送） |

### 与旧方案（K10）的差异

| 按键 | K10 旧方案 | ATK BOX 新方案 | 变更说明 |
|------|-----------|---------------|---------|
| A 长按 | Enter | **Esc** | Esc 从 BOOT 移到 A 长按 |
| B 短按 | 切换界面 | **Enter** | 界面切换交给触摸滑动 |
| BOOT 短按 | Esc | **返回主界面** | 导航功能 |
| BOOT 长按 | 跳转 TouchTest | 跳转 TouchTest | 保持不变 |

**去重理由**：界面切换完全交给触摸滑动后，B 短按释放出来承担 Enter；Esc 归入 A 键，形成"A 键管录音开始/取消"的对称逻辑。

## 3. 全局手势

| 手势 | 触发条件 | 功能 | 适用界面 |
|------|---------|------|---------|
| **左右滑动** | `dx > 60 && dy < 40` | 切换界面（按 `SCREEN_ORDER` 顺序） | 全部界面 |
| **长按空白区域** | 按住 1000ms | 弹出快捷菜单（亮度/返回主界面/设置） | 全部界面（除 TouchTest） |
| **从顶部下拉** | 起点 `y < 40`，向下拖动 `> 80` | 显示通知栏（ESP-NOW 状态/时间） | 全部界面（除 TouchTest） |

**手势冲突处理**：
- 详情卡片打开时，左右滑动被卡片拦截，不触发界面切换
- 长按空白区域必须落在"非交互元素"上（避开列表行、按钮、云朵等）
- 下拉手势起点必须在屏幕顶部 40px 内，避免与界面内点击冲突

## 4. 各界面专属触摸交互

### 界面 0 - ESP-NOW Status

**现有显示**：连接状态、通道号、对端 MAC、音频流状态、发送/失败包数

**新增触摸交互**：
1. **点击 MAC 地址区域** → Toast "MAC 已复制"（仅提示效果）
2. **点击"失败包数"数字** → 重置失败计数器为 0
3. **长按界面中心（1 秒）** → 触发 ESP-NOW 重新配对（发送 PAIR 帧）

**UI 反馈**：点击时元素背景闪烁一次（白色 100ms）；重置计数器后数字变绿色 1 秒

---

### 界面 1 - Token Usage

**现有显示**：4-5 个 AI 服务的 Token 用量（服务名 + 百分比 + 进度条 + 数量）

**新增触摸交互**：
1. **点击某行** → 弹出详情卡片（覆盖层）
   - 内容：服务名、用量趋势小图（最近 7 天折线）、预计耗尽日期、最近更新时间
   - 点击卡片外灰色区域 → 关闭
2. **长按某行（1 秒）** → 标记为"关注"
   - 该行高亮（背景浅黄 0xFFE082）+ 顶部星标图标
   - 再次长按 → 取消关注

**UI 反馈**：详情卡片从右侧滑入（200ms）；长按时显示环形进度条（填满 = 1000ms）

---

### 界面 2 - Project Status

**现有显示**：5-6 个项目（状态圆点 + 项目名 + 状态文字）

**新增触摸交互**：
1. **点击某行** → 弹出项目详情卡片
   - 内容：项目名、完整描述、最后更新时间、状态历史
   - 点击卡片外 → 关闭
2. **点击状态圆点** → 手动切换状态（循环）
   - 顺序：Planning → Coding → Review → Completed → Idle → Planning
   - Toast "Status changed to Coding"
3. **左滑某行（dx < -80）** → 显示红色"删除"按钮
   - 点击删除 → 该行淡出移除
   - 左滑其他行 → 之前的删除按钮隐藏

**UI 反馈**：详情卡片从底部上滑（250ms）；左滑时该行跟随手指，松手吸附

---

### 界面 3 - Product Inspo

**现有显示**：标题、日期、正文、打字机动画

**新增触摸交互**：
1. **点击正文区域** → 暂停/继续打字机动画（"⏸"/"▶" 图标）
2. **双击标题** → 重启打字机动画（清空 → 逐字显示）
3. **长按正文（1 秒）** → 弹出编辑菜单（复制/分享/删除）
   - 复制 → Toast "Text copied"
   - 分享 → Toast "Share not implemented"
   - 删除 → 正文清空显示 "No content"

**UI 反馈**：双击时标题闪烁（白色 150ms）；长按时正文四周蓝色边框渐显

---

### 界面 4 - User Profile

**现有显示**：头像区域（200×240px，SD 卡照片或渐变色块）+ 底部用户名

**新增触摸交互**：
1. **点击头像区域** → 切换下一张照片（循环）
   - 有 SD 卡：`user.png` → `user1.png` → `user2.png` → ...
   - 无 SD 卡：渐变1（蓝紫）→ 渐变2（粉橙）→ 渐变3（青绿）→ 循环
2. **长按头像（1 秒）** → 进入照片管理界面（新增界面 7）
   - 缩略图网格（3×N），点击某张设为头像并返回
3. **点击用户名** → 编辑用户名（弹出虚拟键盘，保存到 NVS）

**UI 反馈**：切换照片时头像缩放动画（缩小 50% → 放大）；长按时头像虚线边框旋转；虚拟键盘从底部上滑

---

### 界面 5 - AI Status（主界面）

**现有显示**：中央旋转圆弧（云朵）、底部状态文字、眨眼动画、情绪自动循环

**新增触摸交互**：
1. **点击云朵中心** → 手动切换情绪（Thinking → Coding → Done → 循环）
   - 停止自动循环，15 秒后恢复
2. **长按云朵（1 秒）** → 暂停/恢复自动循环（圆弧停转 + "⏸" 图标）
3. **点击底部文字** → 编辑自定义状态文字（虚拟键盘，覆盖默认文字直到重启）

**UI 反馈**：点击云朵时圆弧闪烁（白色 100ms）；长按时云朵外围光晕渐显

---

### 界面 6 - TouchTest（调试界面）

**现有功能**：实时坐标显示、绿点跟随、触摸轨迹绘制

**新增触摸交互**：
1. **双击屏幕任意位置** → 清除所有轨迹（Canvas 重置 + 坐标归零）
2. **长按屏幕（2 秒）** → 弹出校准选项菜单
   - 3 个开关：SWAP_XY / FLIP_X / FLIP_Y
   - 点击开关 → 立即生效并保存到 NVS
   - 点击"关闭" → 菜单消失

**UI 反馈**：双击时屏幕闪白（100ms）；长按时坐标文字变红（进度条 = 2000ms）

## 5. 状态转换逻辑

### 界面切换流程

```
[任意界面]
    ├─ 左滑 → 下一个界面（按 SCREEN_ORDER 顺序）
    ├─ 右滑 → 上一个界面
    ├─ 按键 B 短按 → Enter（不再切屏，界面切换交给触摸）
    ├─ 按键 BOOT 短按 → 跳转到界面 5（AI Status 主界面）
    └─ 长按空白区域 → 快捷菜单
           ├─ "返回主界面" → 跳转界面 5
           ├─ "亮度调节" → 滑块调节（范围 10-255）
           └─ "设置" → 进入设置界面（新增界面 8，可选）
```

### 详情卡片生命周期

```
[主界面显示]
    ├─ 点击某行 → 详情卡片滑入
    │       ├─ 点击卡片外灰色区域 → 卡片滑出
    │       ├─ 左滑卡片 → 卡片滑出
    │       └─ 按键 BOOT 短按 → 卡片强制关闭
    └─ 卡片打开时左右滑动 → 不触发界面切换（卡片拦截手势）
```

### 演示模式触发与退出

```
[任意界面]
    ├─ 同时按住 A+B 2 秒 → 进入演示模式
    │       ├─ 注入所有模拟数据
    │       ├─ 跳转到界面 5（AI Status）
    │       └─ 串口输出 "*** DEMO MODE ACTIVATED ***"
    └─ 演示模式激活后：
            ├─ 触摸交互全部生效（含界面 1/2/3/4 专属操作）
            ├─ 长按 BOOT 3 秒 → 退出演示模式（清空数据）
            └─ 重启设备 → 演示模式失效
```

## 6. 用户场景示例

**场景 1 - 查看 Token 详情**：滑到界面 1 → 点击某行 → 详情卡片滑入查看趋势 → 点击卡片外关闭

**场景 2 - 切换项目状态**：滑到界面 2 → 点击橙色圆点 → 状态循环到 Completed → Toast 提示

**场景 3 - 暂停 Inspo 动画**：滑到界面 3 → 点击正文暂停 → 再点击继续 → 双击标题重启

**场景 4 - 切换头像**：滑到界面 4 → 点击头像切换 → 长按进入照片管理 → 选一张返回

**场景 5 - 切换 AI 情绪**：界面 5 点击云朵切换情绪 → 长按暂停自动循环

**场景 6 - 语音输入文件名**（物理键）：短按 A（F2+录音）→ 说文件名 → 短按 A 停 → 短按 B（Enter 确认）

**场景 7 - 删除多余字符**：长按 B（连续 Backspace）→ 松开 → 短按 B（Enter）

**场景 8 - 取消并返回**：长按 A（Esc）→ 短按 BOOT（返回主界面）→ 重新开始

## 7. 实现优先级

| 阶段 | 内容 | 依赖 |
|------|------|------|
| **第一阶段** | 物理按键重新分工（A/B/BOOT）+ 基础点击交互（界面 1/2/4/5 点击响应） | 现有触摸驱动 |
| **第二阶段** | 长按操作 + 详情卡片 UI（界面 1/2）+ 状态圆点切换 | LVGL 覆盖层 |
| **第三阶段** | 下拉通知栏 + 长按快捷菜单 + 虚拟键盘（界面 4/5 编辑） | NVS 存储、键盘组件 |
| **第四阶段（可选）** | 照片管理界面（界面 7）+ 设置界面（界面 8） | 缩略图网格 |

## 8. 技术约束与风险

- **单点触摸**：所有手势基于单点，双击靠时间窗口检测（<300ms 两次点击）
- **长按与滑动冲突**：长按判定需先确认手指未移动（移动 > 20px 则取消长按，转为滑动）
- **LVGL 线程安全**：所有触摸触发的 UI 操作必须持有 `xGuiSemaphore`
- **详情卡片内存**：卡片用完即删（`lv_obj_del`），避免多个卡片叠加占用 PSRAM
- **NVS 写入频率**：用户名/校准参数变更时才写 NVS，避免频繁擦写
- **虚拟键盘**：LVGL v8 `lv_keyboard`，注意布局适配 240px 宽屏
