核心功能特性

🚀

在线烧录

基于 Web Serial API，浏览器直接烧录 ESP32 固件，无需安装驱动或工具链

🎯

智能筛选

分类标签快速切换，按项目类型过滤展示，提升浏览效率

🔒

芯片校验

烧录前自动验证芯片型号，防止误刷导致设备损坏

🎨

实物图展示

卡片支持产品实物图背景，自动适配横竖图布局

⚡

连续烧录

支持烧录多个设备，自动断开旧连接并引导重连新设备

📦

完全离线

纯静态实现，固件文件本地处理，不上传任何数据到服务器

🔧

自动检测

根据项目文件智能判断类型，自动配置烧录参数和交互流程

📱

多端适配

响应式设计，桌面和移动端均可访问（固件烧录需桌面浏览器）

技术栈

Web Serial API esptool-js 0.5.7 纯静态 HTML/CSS/JS Chrome/Edge 89+ ESP32/S2/S3/C3 Python 自动化脚本 GitHub Pages 零后端依赖
