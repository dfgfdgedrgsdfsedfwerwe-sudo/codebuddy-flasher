🚀 快速启动

1启动 Bonsai 服务栈

C:\bonsai\start-bonsai-stack.ps1

此脚本会启动：

  • llama-server: 在后台运行 Bonsai 模型推理服务
  • LiteLLM 代理: 将 Anthropic API 请求转换为 OpenAI 格式

2使用 Bonsai 模型

方式一：交互式对话

cd C:\bonsai\claude-bonsai
claude --model bonsai2-27b

方式二：单次命令

cd C:\bonsai\claude-bonsai
claude --model bonsai2-27b --print "你的提示词"

⚠️ 重要说明

🔒 配置隔离

  • 全局设置不变: ~/.claude/settings.json 保持指向正常 Claude 服务 (http://127.0.0.1:10048)
  • Bonsai 专用目录: 只在 C:\bonsai\claude-bonsai 目录下使用才会调用本地模型
  • 配置备份: ~/.claude/settings.json.bak-bonsai

⚙️ 技术细节

  • 推理引擎: PrismML-Eng/llama.cpp (官方 llama.cpp 不支持 ternary 模型)
  • 可执行文件: llama-server.exe (不是 main.exe)
  • GPU 加速: CUDA 13.3 (-DGGML_CUDA=ON)
  • 模型加载: -ngl 99 (全部层加载到 GPU)
  • Flash Attention: -fa on
  • 聊天模板: --chat-template chatml (必需，GGUF 自带模板不兼容 Claude Code)

🔧 故障排除

问题 1: 服务无法启动

检查步骤:

# 检查端口是否被占用
netstat -ano | findstr "8080"
netstat -ano | findstr "4000"

# 如果被占用，终止进程
taskkill /PID <进程ID> /F

问题 2: 推理速度过慢

可能原因:

  • GPU 未正确加载模型（检查 -ngl 参数）
  • 其他程序占用 GPU 资源
  • 显存不足导致部分模型在 CPU 运行

检查方法:

nvidia-smi

问题 3: "System message must be at the beginning" 错误

解决方案: 确保 llama-server 启动时包含 --chat-template chatml 参数

问题 4: Claude Code 无法连接

检查清单:

  1. 确认已运行 start-bonsai-stack.ps1
  2. 确认当前目录在 C:\bonsai\claude-bonsai
  3. 检查 .claude\settings.json 中的 ANTHROPIC_BASE_URL 设置

🛑 停止服务

方式一: 使用任务管理器

找到并结束以下进程：

  • llama-server.exe
  • litellm (Python 进程)

方式二: 使用 PowerShell

# 停止 llama-server
Get-Process llama-server -ErrorAction SilentlyContinue | Stop-Process -Force

# 停止 LiteLLM
Get-Process python -ErrorAction SilentlyContinue | Where-Object {$_.CommandLine -like "*litellm*"} | Stop-Process -Force
